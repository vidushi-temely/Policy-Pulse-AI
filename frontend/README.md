# PolicyPulse AI - Frontend Client

This is the Vite-React frontend client for PolicyPulse AI. It connects to the FastAPI backend at `http://127.0.0.1:8000` to deliver a premium, real-time command center interface.

## Quick Start
1. Install node dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.
